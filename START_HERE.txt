JARVIS — FIRST-WEEK STARTER

Built for your Windows 11 PC, Ryzen 7 5700X, 32 GB RAM and RTX 5070 12 GB.
The code is ready to try. Running the real model and checking GPU speed still
need to happen on your PC.

1. Extract the ZIP completely to a folder on your SSD.
   Example: C:\Projects\Jarvis
   Open the extracted jarvis_starter folder, not the ZIP preview.

2. If you do not already have them, install:
   - Ollama for Windows: https://ollama.com/download/windows
     Use its manual Windows installer and then open the Ollama app.
   - Python, 64-bit: https://www.python.org/downloads/windows/
     Python 3.13 is a sensible Windows choice; this code was tested on 3.12.
     Choose the normal installer, not the embeddable package.
     Enable the Python launcher / Add Python to PATH options if offered.
   - For the coding and Git steps, install these too:
     VS Code: https://code.visualstudio.com/download
     Git: https://git-scm.com/install/windows

3. Double-click SETUP_MODEL.bat.
   This runs: ollama pull qwen3:8b
   The model is about a 5.2 GB download. Leave room for dependencies too;
   aiming for at least 20 GB free on the relevant SSD is a practical buffer.
   By default Ollama keeps models in your Windows user profile, which may
   be on a different drive from the project.

4. Double-click START_JARVIS.bat.
   On its first run, it creates a private .venv and installs Streamlit.
   This first setup needs internet. Later launches reuse that environment.
   Keep the terminal window open while using Jarvis.
   Your browser should open at: http://127.0.0.1:8501
   If it does not, open that address yourself.

5. Send: "My project is called Atlas. Help me plan a Python task tracker."
   Then ask: "What did I call my project?"
   It should use the earlier message in this same conversation.

6. Stop Jarvis with Ctrl+C in its terminal, then run START_JARVIS.bat again.
   Your messages should still be there. Reopen the saved conversation.
   Saved history is not yet intelligent memory across different chats.

7. Run CHECK_SETUP.bat. While Jarvis is answering a question, open a
   second terminal and run: ollama ps
   Record what the PROCESSOR column shows. Real GPU performance is not
   verified until you check it here.

8. Work through BASELINE_PROMPTS.md and TODAY_CHECKLIST.md.
   RUN_TESTS.bat runs the automated app checks using a fake local server;
   it does not test the actual model's intelligence or GPU speed.

9. Open this folder in VS Code and read chat_cli.py, app.py, then jarvis/.
   README.md explains each part. Add a note to DEVELOPMENT_LOG.md about
   something you changed and can explain yourself.

10. Use the Git commands in README.md to save your first local commit.

If something fails, copy the error text or send a screenshot of the terminal.
No paid API key is needed for this version.
