# Jarvis Mobile Analyzer

This is an installable progressive web app for iPhone and other mobile browsers. It performs a private, on-device review of pasted Python code.

## Install on iPhone

1. Host this folder over HTTPS.
2. Open the site in Safari.
3. Tap **Share** then **Add to Home Screen**.

The package cannot be installed directly from a ZIP or `file://` URL because iPhone service workers and PWA installation require HTTPS. The mobile web app cannot control iPhone VPN settings; use an installed VPN provider app.
