# Production roadmap after the first D5 Render image

1. Produce 3 static frames: hero lab, command deck, avatar workshop.
2. Decide what the robot looks like; refine actual geometry in Blender.
3. Install D5 LiveSync for Blender from the official launcher/workflow page.
4. Make every robot part a purposeful Blender object: head, jaw/visor,
   torso, left/right upper/lower arm, hand, thigh, shin, feet.
5. Use Blender rigging for motion, animation and vertex weights.
6. Export updated visuals and produce cinematic stills in D5.
7. For interactive VR and voice integration, use a separate realtime VR engine
   (such as Unreal Engine or Unity) plus JARVIS's local Python services.

D5 is primarily a rendering tool, NOT the interactive JARVIS AI/VR runtime.
