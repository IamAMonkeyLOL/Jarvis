YOUR WORKSPACE, YOUR CONNECTION

Ready when
you are.

This website runs on GitHub Pages. Connect a hosted backend to enable live AI chat.

AI connection

Use your own HTTPS chat endpoint. Keep provider API keys on your server — never in this page or repository.

Backend connection format

The endpoint must accept a JSON POST with {"messages":[{"role":"user","content":"Hello"}]} and return {"reply":"Hello!"}. Allow this site’s origin through CORS. Set up access controls, usage limits, and your provider key on the backend before sharing it with users. Conversation text is sent to that service only when you send a message in connected mode.

Local storage

Conversation history and the endpoint URL are saved in this browser. Demo messages never leave this page. Export your conversation before clearing it.
